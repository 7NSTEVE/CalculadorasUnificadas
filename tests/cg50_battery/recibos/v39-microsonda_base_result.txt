RESPUESTA: NO. El submenu LOGIC de RUN-MAT tiene UNA SOLA pagina.
  Evidencia (bas-f1, secuencia kMenu kDigUno kExit kOptn kF6 kF6 kF4
  kF6 kF5 kF6):
    p2  OPTN pag1 = LIST | MAT | CPLX | CALC | STAT | >
    p3  OPTN pag2 = HYPERBL | PROB | NUMERIC | ANGLE | >
    p4  OPTN pag3 = ENG-SYM | FINANCE | LOGIC | >
    p5  kF4 abre LOGIC = And | Or | Not | Xor   (4 slots, kF1..kF4)
    p6  kF6 -> MISMA pantalla (And|Or|Not|Xor): no hay pagina 2
    p7  kF5 -> MISMA pantalla
    p8  kF6 -> MISMA pantalla
  Conclusion: 'Dec / 'Hex / 'Bin / 'Oct NO existen en OPTN->LOGIC.
  Toda la via LOGIC (v34-v38) queda DESCARTADA como ruta a Base-N.

corrige en este recibo: queda anotado para el frente de SETUP.
